original generated models and not meshes taken from Valheim or another game.
All upstream assets below are released under [CC0 1.0](https://polyhaven.com/license)

## Adaptation and reproducibility

- `sources.json` pins source URLs, upstream MD5 checksums, sizes, authors and
  runtime texture SHA-256 fingerprints. Rebuild downloads reuse those pinned
  entries, rather than resolving a new upstream revision.
- `meshes.json` records original object names, dimensions in Blender XYZ meters,
  full exported triangle counts and exported GLB SHA-256 fingerprints.
- Corner `UVMap` vector attributes are restored as exportable UV coordinates.
  Authored geometry/branch structure is preserved; no billboard replacement,
  generative repainting, smooth proxy crown or silhouette reconstruction.
- Needle/fern color and alpha are combined into RGBA PNGs. Remaining maps are
  RGB JPEGs, at most 1024px. Godot materials use lit alpha-scissor foliage,
  normal maps on imported plants/rocks, and mipmapped textures.
- The clinic/traveler and path-margin grass are original project geometry,
  outside this directory. The clinic uses color texture projection; it is not
  a new scanned clinic or a fully authored production character.
- The refined grove ground in `../grove-terrain` is an **offline derivative** of
  the three CC0 `forest_floor`, `forrest_ground_01` and `mossy_rock` color and
  normal maps. Its `terrain.json` pins the builder, six input files, placement
  coordinates and two resulting 2048px JPEG fingerprints. Nothing is sampled
  from a screenshot or generated by an image model.

From the repository root (Pillow and Blender 4.5.3 required **only** to rebuild):

```sh
mkdir -p "$HOME/forest-source-cache"
python3 prototype/tools/fetch_reference_forest.py --cache "$HOME/forest-source-cache"
blender --background --python prototype/tools/build_reference_forest.py -- --cache "$HOME/forest-source-cache"
make import
```

The 219MB source tree Blender file is not checked in. No network, Blender,
NumPy or Pillow is required to run the scene with the committed runtime assets.
Rebuilding the refined ground requires NumPy and Pillow, but not Blender or a
source download:

```sh
python3 prototype/tools/build_grove_terrain.py
make import
```

This is a **visual quality reference**, not an optimized production asset pack:
the three tree variants contain 70,661 / 54,927 / 31,512 full-detail triangles.
The grove places nineteen trees, approximately **1.04M tree triangles** before
Godot's generated mesh LODs. Alpha overdraw and target-hardware performance
still need profiling; passing a software-render smoke test is not a frame-rate
or mobile budget claim.
